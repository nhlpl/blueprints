## 3. Code: Generate Golden‑Ratio Music (MIDI)

The following Python script generates a short melody using the golden‑ratio scale and rhythm, and saves it as a MIDI file.

```python
import math
import random
import mido
from mido import Message, MidiFile, MidiTrack

PHI = 1.618033988749895
BASE_FREQ = 440.0  # A4
NOTES = ['C', 'C#', 'D', 'D#', 'E', 'F', 'F#', 'G', 'G#', 'A', 'A#', 'B']
TEMPO_BPM = 100 / PHI          # 61.8 BPM
BEATS_PER_BAR = 10 / PHI       # 6.18
TICKS_PER_BEAT = 480
US_PER_TICK = int(60_000_000 / (TEMPO_BPM * TICKS_PER_BEAT))

def freq_to_midi_note(freq):
    return int(round(69 + 12 * math.log2(freq / 440.0)))

def golden_scale(root_note=0):
    # root_note: 0 = A, 1 = A#, etc.
    f0 = BASE_FREQ * (2 ** (root_note / 12))
    return [f0 * (PHI ** (n/12)) for n in range(12)]

# Generate a melody using the Fibonacci word
fib_word = "ABAABABA"  # 8 notes
scale = golden_scale(9)  # start on A? Actually index 9 = A? Let's use A as index 9
notes = [freq_to_midi_note(scale[i % 12]) for i, c in enumerate(fib_word)]

# Create MIDI file
mid = MidiFile()
track = MidiTrack()
mid.tracks.append(track)
track.append(mido.MetaMessage('set_tempo', tempo=US_PER_TICK))
track.append(Message('program_change', program=0, channel=0))

for note in notes:
    track.append(Message('note_on', note=note, velocity=64, time=0))
    track.append(Message('note_off', note=note, velocity=64, time=int(TICKS_PER_BEAT * 0.618)))

mid.save('golden_melody.mid')
print("Golden‑ratio melody saved as 'golden_melody.mid'")
```

This code requires the `mido` library (`pip install mido`). It produces a MIDI file that can be played with any standard player.
